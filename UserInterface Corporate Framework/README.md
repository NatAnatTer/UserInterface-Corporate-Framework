# n.terzyan
# UserInterface Corporate Framework
### Описание

Этот проект содержит автоматизированные UI-тесты для веб сайта https://userinyerface.com/. Тесты проверяют корректность работы пользовательского интерфейса, включая переходы между страницами, взаимодействия с формами, элементами, загрузка изображения из файловой системы на страницу.

### Инструкция для запуска
Для запуска тестов необходимо добавить конфигурационный файл настройки веб-драйвера settings.json и тестовый конфигурационный файл с тестовыми параметрами config_test.json. Затем проверить пути к конфигурационным файлам в ParseDataUtil.
Для запуска тестов в браузере Chrome необходимо в файле settings.json указать параметр:
```json
{
  "browserName": "chrome"
}

```
Для запуска тестов в браузере Firefox необходимо добавить конфигурацию:
```json
{
  "browserName": "firefox"
}
```

### Реализованные тесты
#### Test case 1
В части UI, тест автоматизирует переходы между страницами, заполнение формы регистрации и подтверждения соглашений, загрузка изображений из файловой системы на страницу, а также работа со списком элементов, поиск по списку и взаимодействие.

#### Test case 2
В части UI, тест автоматизирует взаимодействие с модальным элементом формы помощи. Реализует скрытие формы и ожидание когда элемент станет невидимым.

#### Test case 3
В части UI, тест автоматизирует взаимодействие с модальным элементом формы cookies.Реализует нажатие на кнопку "принять" и ожидание выполнения действия.

#### Test case 4
В части UI, тест автоматизирует взаимодействие с элементом "таймер", получение его значения.

### Технологии
Автотесты написаны на Java с использованием TestNG, применены различные библиотеки и фреймворки. При написании использованы библиотеки lombok для автоматической генерации конструкторов и геттеров, сеттеров, jackson-databind для парсинга JSON-файлов, фреймворк aquality-selenium веб драйвер, robotframework - для взаимодействия с файловой системой ОС.
